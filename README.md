# sabasunten.id - Portal & Marketplace Desa Wisata Suntenjaya

Portal pariwisata terpadu dan marketplace resmi untuk **Desa Wisata Suntenjaya**, Kecamatan Lembang, Kabupaten Bandung Barat, Jawa Barat.

> **Deskripsi Profil:**  
> *Desa Suntenjaya menawarkan keindahan lanskap pegunungan yang asri, udara sejuk, serta budaya masyarakat lokal yang otentik. Menjadi destinasi unggulan untuk melepas penat di Kabupaten Bandung Barat.*

> **Konteks Proyek & Kolaborasi Nyata:**  
> Dikembangkan sebagai karya Tugas Akhir / Skripsi program studi **Desain Komunikasi Visual (DKV)** dalam perancangan identitas visual, kampanye digital, dan media informasi interaktif desa wisata, berkolaborasi langsung secara riil dengan **Pemerintah Desa Suntenjaya** dan **Pokdarwis Saba Sunten**.

## Profil & Integrasi Pemerintahan Desa

Portal ini diselaraskan dengan data resmi Pemerintah Desa Suntenjaya (Kecamatan Lembang, Kabupaten Bandung Barat) dan portal administrasi kependudukan **SILAMOT** ([desasuntenjaya.site](https://desasuntenjaya.site)):

- **Kepala Desa:** H. Asep Wahyono
- **Sekretaris Desa:** Iwan Setiawan
- **Luas Wilayah:** 845 Ha | **Penduduk:** 12.450 Jiwa | **Ketinggian:** 1.290 mdpl
- **Visi Desa:** *"Terwujudnya Desa Suntenjaya yang Mandiri, Sejahtera, Berbudaya, dan Berbasis Digital Terdepan di Kabupaten Bandung Barat."*
- **4 Wilayah Dusun:**
  - **Dusun I (Pasir Angling):** Homestay tertinggi lereng gunung, spot sunrise, agrowisata sayur organik terasering. (Kadus: Hilman Nugraha)
  - **Dusun II (Batu Loceng):** Cagar budaya megalitikum Batu Loceng, saung budaya, kebun Kopi Arabika Single Origin. (Kadus: Kiki Andrian)
  - **Dusun III (Cikawari & Bincarung):** Wisata hutan pinus Taman Bincarung, sentra sapi perah KPSBU Lembang. (Kadus: Vicky Permana Putra)
  - **Dusun IV (Suntenjaya Pusat):** Kantor Desa & Layanan SILAMOT, kerajinan miniatur kereta kayu Kadaplak. (Kadus: Sandi Agustin E.P.)

## Fitur Utama & Panduan Demo (Skripsi & Pemdes)

- 🎭 **Pengalih Peran Instan (Quick Demo Role Switcher):** Berpindah peran dalam 1-klik antara **Wisatawan** (`Budi`) dan **Pengelola Desa / BUMDes** (`Kang Asep Suhendar`) langsung melalui header navbar atau halaman autentikasi.
- 🏛️ **Dashboard Pengelola BUMDes & Pokdarwis Saba Sunten:** Manajemen terpadu produk homestay, sayur organik, susu murni, kopi desa, inventaris stok, serta pantau status pesanan wisatawan secara real-time.
- 🏡 **Pemesanan Homestay & Saung Warga:** Kalkulasi durasi menginap (malam) secara dinamis, pemilih tanggal check-in/out, dan pesan otomatis terformat via WhatsApp resmi.
- 🧾 **E-Ticket & Bukti Reservasi Resmi Siap Cetak:** Penerbitan resi dan e-ticket resmi Pokdarwis Saba Sunten lengkap dengan QR Code kedatangan dan format cetak PDF (`window.print()`).
- ☕ **Katalog Produk Khas Desa:** Kopi Arabika Suntenjaya Single Origin, Susu Sapi Segar Murni, Yoghurt Probiotik, dan Sayuran Organik Segar panen langsung petani.
- 🎒 **Paket Wisata & Live-In:** Paket edukasi perah susu sapi, petik sayur, roasting kopi, napak tilas Situs Batu Loceng, dan permainan tradisional balap kayu Kadaplak dengan filter aktivitas.
- 📲 **Alur Transaksi Cepat & Realistis via WhatsApp:** Menghubungkan calon wisatawan langsung ke kontak resmi Pokdarwis Saba Sunten tanpa perlu login merchant yang rumit.
- 🏛️ **Integrasi Layanan Digital SILAMOT:** Tautan langsung ke sistem administrasi surat & kependudukan resmi desa ([desasuntenjaya.site](https://desasuntenjaya.site)).

## Cara Menjalankan Aplikasi

1. Pasang dependensi (menggunakan Bun untuk kecepatan maksimal):
   ```bash
   bun install
   ```

2. Jalankan server pengembangan (Vite):
   ```bash
   bun run dev
   ```

3. Build untuk produksi:
   ```bash
   bun run build
   ```
