# Saba Lembang - Platform Interdesa Kawasan Lembang

Platform pariwisata terpadu dan marketplace resmi untuk **Desa Wisata di Kawasan Lembang**, Kabupaten Bandung Barat, Jawa Barat.

> **Deskripsi Platform:**  
> *Saba Lembang menghubungkan wisatawan dengan keindahan alam pegunungan (1.200 - 1.400 mdpl), sembako & susu murni harian, tanaman hias, kopi specialty, buah & herba, kuliner khas, olahan susu, paket wisata alam, dan penginapan lokal langsung terhubung ke Admin Desa resmi tiap kawasan.*

> **Konteks Proyek & Kolaborasi Nyata:**  
> Dikembangkan sebagai karya Tugas Akhir / Skripsi program studi **Desain Komunikasi Visual (DKV)** dalam perancangan identitas visual, kampanye digital, dan media informasi interaktif desa wisata, berkolaborasi dengan jajaran **Pemerintah Desa & Pengurus Pokdarwis** di kawasan Lembang.

## 📊 Analitik Corong Pengunjung & Konfirmasi Pembelian (Funnel Analytics - Opsi A)
Melacak interaksi pengunjung tanpa membutuhkan server backend berbayar (zero-cost serverless di Vercel SPA):
- **Pelacakan Langkah Lengkap Corong Wisatawan:**
  1. **Tap Produk:** Mencatat setiap kali kartu produk dilihat/diklik pengunjung.
  2. **Pencarian Kata Kunci:** Mencatat query pencarian populer dan jumlah hasil yang ditemukan.
  3. **Chat WA (Leads):** Mencatat klik tombol *"Beli Langsung via WhatsApp"* atau *"Tanya Admin Desa"* sebagai prospek pembeli baru (otomatis terdaftar di tab pesanan dasbor).
  4. **Deal / Pembelian Lunas (Opsi A):** Admin Desa dapat mengonfirmasi pesanan yang telah lunas/selesai langsung dari dasbor dengan menekan tombol **"✅ Deal / Lunas"**, yang secara instan menghitung rasio konversi (*Conversion Rate*) dan omzet riil.
- **Kompatibilitas Google Analytics 4 (GA4):** Semua event juga diteruskan secara otomatis ke `window.gtag` jika ID GA4 dikonfigurasi.

## 💳 Integrasi Payment Gateway Midtrans (Sandbox Snap)
Platform telah terintegrasi dengan payment gateway resmi **Midtrans Snap (Sandbox)**:
- **Metode Pembayaran Digital Lengkap:** QRIS (GoPay, OVO, Dana, ShopeePay, BCA Mobile), Virtual Account Bank (BCA, Mandiri, BRI, BNI), dan Kartu Debit/Kredit.
- **Arsitektur Aman & Portabel (Zero Vendor Lock-in):**
  - **Server Key Terlindungi:** Kunci rahasia server disimpan aman di server side (`.env`) dan tidak bocor ke bundle JavaScript browser.
  - **Vercel Serverless Function (`api/midtrans-token.ts`):** Endpoint serverless gratis yang langsung aktif saat di-deploy ke Vercel.
  - **Cloudflare Pages Function Fallback (`functions/api/midtrans-token.ts`):** Kompatibel 1:1 sehingga dapat dipindahkan ke Cloudflare Pages kapan saja tanpa mengubah kode frontend.
  - **Local Development Middleware (`vite.config.ts`):** Pengujian lokal saat `bun run dev` langsung terhubung ke Midtrans Sandbox tanpa perlu server backend eksternal.
- **E-Ticket Otomatis:** Setelah simulasi pembayaran berhasil, status transaksi langsung tercatat **Lunas**, memicu pelacakan konversi otomatis, dan membuka E-Ticket resmi siap cetak.
- **Backup Manual WhatsApp:** Opsi konfirmasi langsung via WhatsApp Admin Desa tetap tersedia sebagai alternatif.
- **Panduan Uji Coba Pembayaran:** Langkah simulasi pembayaran online dan cetak tiket dapat dilihat di [docs/PANDUAN_SIMULASI_MIDTRANS.md](docs/PANDUAN_SIMULASI_MIDTRANS.md).

## 🔄 Pipeline Pembersihan Data Riil Klien & Kompresi WebP (Adaptive Pipeline)

Platform dilengkapi script pemrosesan otomatis berbasis `uv` untuk membaca data riil lapangan dari klien tanpa mengubah file mentah (`assets/real_data_from_client/list produk unggulan marketplace lembang.tsv`):

```bash
# Jalankan pipeline pembersihan data riil dan kurasi gambar
uv run scripts/process_client_data.py
```

- **Data Provenance:** Produk ditandai secara transparan dengan metadata `dataSource: 'real'` (Data Riil Mitra) dan `dataSource: 'dummy'` (Simulasi / Mock) yang dapat difilter di Marketplace.
- **Kompresi Gambar WebP:** Foto DSLR/HP beresolusi besar (5-12MB) dikurasi dan dikonversi otomatis menjadi format WebP berkualitas tinggi dengan ukuran ringan (~60KB - 250KB) di `public/images/client/`.
- **Adaptif Terhadap Penambahan Baris Baru:** Setiap baris baru yang ditambahkan klien ke file TSV akan otomatis terdeteksi, dibersihkan nomor WhatsApp-nya, dan diintegrasikan ke modul TypeScript `src/data/realProducts.ts`.
- **Pelacak & Log Kurasi Media (Tracker):** Seluruh berkas gambar dan video yang diunduh dari klien (153 berkas) diaudit dan dicatat dalam manifes data `assets/real_data_from_client/media_curation_manifest.json` serta laporan transparan di `docs/MEDIA_CURATION_TRACKER.md`. Jika klien memasukkan foto baru ke folder unduhan, pelacak akan mendeteksinya secara otomatis.

### 📋 Alur Kerja Saat Ada Penambahan Data / Foto Baru:
1. **Jika Klien Mengirim Baris TSV Baru:** Cukup simpan perubahan di `assets/real_data_from_client/list produk unggulan marketplace lembang.tsv`.
2. **Jika Klien Mengirim Foto Baru:** Masukkan foto ke folder terkait di `assets/real_data_from_client/<Folder>/`.
3. **Jalankan Pipeline:**
   ```bash
   uv run scripts/process_client_data.py
   ```
4. **Verifikasi:** Jalankan `bun run lint && bun run build` dan periksa laporan kurasi terbaru di `docs/MEDIA_CURATION_TRACKER.md`.

## 🔒 Midtrans Webhook Engine & Verifikasi SHA-512 (Production Ready)

Untuk menangani notifikasi pembayaran riil dari Midtrans secara asinkron tanpa bergantung pada peramban pengunjung:
- **Endpoint Vercel:** `api/midtrans-notification.ts`
- **Endpoint Cloudflare Pages:** `functions/api/midtrans-notification.ts`
- **Dev Server Middleware:** Terintegrasi di `vite.config.ts` untuk pengujian lokal (`/api/midtrans-notification`).
- **Keamanan Signature:** Memverifikasi hash `SHA512(order_id + status_code + gross_amount + ServerKey)` dengan proteksi *timing attacks* (`crypto.timingSafeEqual`). Request palsu otomatis ditolak dengan `403 Forbidden`.

### 🧪 Simulasi Webhook via CLI:
```bash
# Uji coba payload Midtrans (Settlement, Expired, dan Anti-Spoof Tampered Attack)
uv run scripts/test_webhook.py

# Atau tembak ke endpoint custom / production
uv run scripts/test_webhook.py https://sabalembang.id/api/midtrans-notification
```
